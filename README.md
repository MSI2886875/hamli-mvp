# هملی — MVP مستقل

وب‌اپ مراقبت و ارتباط روزانه سالمند و عضو اصلی خانواده، مبتنی بر Next.js و Supabase.

## قابلیت‌های پیاده‌سازی‌شده

- ثبت‌نام و ورود سالمند و خانواده با شماره موبایل و رمز ثابت، بدون هزینه پیامک
- تولید کد اتصال سالمند و اتصال فقط با تطابق شماره عضو خانواده
- اتصال چند سالمند به یک عضو خانواده و انتخاب نسبت
- قطع اتصال توسط سالمند یا خانواده بدون حذف اطلاعات
- بازنشانی رمز سالمند توسط عضو اصلی خانواده
- سه نوبت ثابت ثبت وضعیت و تاریخچه مجزا
- ثبت خوبم، معمولی‌ام و خوب نیستم با سه سطح نیاز
- تأیید وضعیت و پیام اختیاری خانواده
- ثبت تماس انجام‌شده یا تماس در زمان دقیق بعدی
- هشدار اضطراری و خاتمه فقط توسط خانواده با نتیجه اختیاری
- خروج از خانه، مقصد، توضیح، بازگشت نیم‌ساعتی، درخواست خودرو و اطلاعات اختیاری خودرو
- درخواست موقعیت توسط خانواده، پاسخ سالمند، اشتراک ۳۰دقیقه‌ای و ثبت موقعیت هنگام بازگشت
- تمدید زمان بازگشت تا پایان همان روز
- صندوق «یادت باشه» با عنوان، متن و دو پاسخ سریع
- پرونده پزشکی، گزارش، تصویر/PDF، دارو و دوره مصرف، ویزیت، مخاطبین پزشکی
- تاریخ‌های خاص، یادداشت خانواده و یادآوری‌های داخل برنامه
- تاریخچه وضعیت و رفت‌وآمد به‌صورت جداگانه
- کنترل دسترسی سطری RLS برای تمام جداول و فضای فایل خصوصی

## ساختار فنی

- Next.js 16
- Supabase Auth، Postgres، Storage و RLS
- میزبانی پیشنهادی: Vercel
- تاریخ‌ها در دیتابیس میلادی ذخیره می‌شوند؛ نمایش‌های فارسی با `Intl` انجام می‌شود.

## راه‌اندازی مرحله‌به‌مرحله

### ۱. ساخت پروژه Supabase

1. وارد `https://supabase.com/dashboard` شوید.
2. گزینه **New project** را بزنید.
3. یک نام مانند `hamli-mvp` و رمز قوی دیتابیس تعیین کنید.
4. منطقه نزدیک‌تر به کاربران را انتخاب کنید و منتظر آماده‌شدن پروژه بمانید.

### ۲. ساخت دیتابیس و دسترسی‌ها

1. از منوی پروژه وارد **SQL Editor** شوید.
2. فایل زیر را باز کنید و تمام محتوای آن را در SQL Editor اجرا کنید:

   `supabase/migrations/202608300001_initial_schema.sql`

3. از **Storage** بررسی کنید که bucket خصوصی `medical-files` ساخته شده باشد.
4. از **Table Editor** وجود جدول `profiles` را بررسی کنید.

### ۳. دریافت کلیدهای اتصال

1. در Supabase روی **Connect** بزنید.
2. این سه مقدار را بردارید:
   - Project URL
   - Publishable key
   - Secret key
3. کلید Secret را هرگز در کد عمومی یا متغیر `NEXT_PUBLIC_` قرار ندهید.

### ۴. اجرای آزمایشی روی کامپیوتر

1. Node.js نسخه 22 یا جدیدتر را نصب کنید.
2. در پوشه پروژه دستور زیر را اجرا کنید:

   ```bash
   npm install
   ```

3. فایل `.env.example` را با نام `.env.local` کپی کنید.
4. مقادیر واقعی Supabase را در آن قرار دهید:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxx
   SUPABASE_SECRET_KEY=sb_secret_xxx
   ```

5. پروژه را اجرا کنید:

   ```bash
   npm run dev
   ```

6. آدرس `http://localhost:3000` را باز کنید.

### ۵. قراردادن کد در GitHub

1. در `https://github.com/new` یک repository خصوصی بسازید.
2. فایل‌های پروژه را در آن بارگذاری کنید.
3. فایل‌های `.env.local` و کلید Secret را در GitHub قرار ندهید.

### ۶. انتشار رایگان در Vercel

1. وارد `https://vercel.com/new` شوید.
2. حساب GitHub را متصل و repository هملی را Import کنید.
3. Framework باید به‌صورت خودکار **Next.js** تشخیص داده شود.
4. در بخش **Environment Variables** همان سه متغیر مرحله ۴ را ثبت کنید.
5. گزینه **Deploy** را بزنید.
6. پس از انتشار، آدرس Vercel را باز کنید.

### ۷. سناریوی تست

1. در یک مرورگر حساب سالمند بسازید و کد اتصال را یادداشت کنید.
2. در مرورگر یا حالت Incognito حساب خانواده با همان شماره‌ای که سالمند معرفی کرده بسازید.
3. کد سالمند و نسبت را در «افزودن سالمند» وارد کنید.
4. با حساب سالمند وضعیت ثبت کنید.
5. با حساب خانواده وضعیت را تأیید و پیام ارسال کنید.
6. خروج، درخواست موقعیت، درخواست خودرو، یادت‌باشه و پرونده سلامت را بررسی کنید.

## کنترل نهایی قبل از تست واقعی

- Site در Vercel فقط برای تیم تست ارسال شود.
- از اطلاعات پزشکی واقعی، مدارک هویتی یا اطلاعات حساس استفاده نشود.
- کلید Secret فقط در تنظیمات Vercel نگهداری شود.
- پیش از عرضه عمومی، محدودسازی ثبت‌نام، ثبت رویداد امنیتی، پشتیبان‌گیری و سیاست حریم خصوصی اضافه شود.

## محدودیت نسخه MVP

- اعلان‌ها فقط داخل برنامه هستند و Push/SMS ندارند.
- یادآوری‌ها هنگام بازشدن داشبورد خانواده محاسبه می‌شوند.
- دریافت GPS نیازمند اجازه مرورگر و HTTPS است؛ Vercel به‌صورت پیش‌فرض HTTPS دارد.
- برای انتشار تجاری باید پلن میزبانی متناسب و الزامات حقوقی/امنیتی بررسی شود.
